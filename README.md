## ⚡ Overview

A personal developer operating system and portfolio platform built with:
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 (Custom obsidian & copper design language)
- **3D Graphics**: Three.js WebGL (Interactive developer workstation with Raycasting & tech node picking)
- **Icons**: Lucide React
- **Sound**: Web Audio API synthesized developer micro-interactions
- **Integrations**: Raycast-style Command Palette (`Ctrl + K`), Interactive Terminal Shell, Curriculum Vitae PDF/Markdown export, and verified project archive.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
